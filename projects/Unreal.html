Unreal Engine Showcase

A final-year university project demonstrating character rigging, gameplay mechanics, and environment building.

For this project, I handled the core programming and technical art required to create a fully playable world. While some background environmental props were sourced from Fab, the logic, interactions, and character assets were built entirely from scratch.

Core Contributions
  • Character Tech Art: Rigged, animated, and hand-textured the two main characters.
  • Gameplay Programming: Scripted all world interactions, mechanics, and gameplay loops.
  • World Building: Assembled and lit the environment to showcase Unreal's graphics capabilities.
