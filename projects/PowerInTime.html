Power In Time Controller

A basic character controller for a 2d character in Unity.

This project features a responsive character controller that prototypes core mechanics for an upcoming 2.5D platformer. It also showcases a custom 3D-to-2D asset pipeline, converting rigged Blender animations into optimized Unity spritesheets to streamline workflow.

Play the Game

Controls

  • A D — Move
  • Space — Jump (Jump off a wall to wall-jump)
  • Shift — Sprint
  • Ctrl — Roll
  • LMB — Attack
  • F — Interact (with the orb)
  • Run into a wall — Wall Slide
