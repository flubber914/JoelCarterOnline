The Secret Blue Forest

Full lifecycle production from initial concept to release on Steam.

The Secret Blue Forest is a puzzle-adventure game developed entirely from the ground up in Unity. Serving as the sole programmer and designer, I architected the core gameplay loops, custom physics interactions, and enemy AI, managing the entire production pipeline through to a public launch. The project required balancing scalable, performant systems with responsive game feel, specifically focusing on spatial puzzles and combat encounters.

Core Contributions
  • Recursive Puzzle Mechanics: Engineered modular spatial boundary checks utilizing dynamic object scaling. This allowed for chained, Sokoban-style block-pushing interactions, enabling the player to manipulate multiple stacked physical objects simultaneously.
  • State-Driven Enemy AI: Developed dynamic decision trees for enemy behavior based on spatial proximity. Implemented weighted Random Number Generation to organically adjust an enemy's aggression state
  • End-to-End Deployment: Managed the complete technical lifecycle, moving from raw prototype to commercial build. This included memory management, audio coroutine sequencing, and integration with the Steamworks backend for final storefront distribution.
